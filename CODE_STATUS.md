# Code status

This is a rough-draft scaffold for `https://github.com/jeramee/evidence-ai-core`.

This repository is Project 1 only.

## Owns

- static/local evidence packet creation
- packet record contracts
- SHA-256 artifact hashing
- mechanical verification
- conservative authority flags

## Does not own

- RunLab notebook execution
- txtai execution
- paperetl execution
- paperai execution
- TraceLab lab/instrument orchestration
- source-control mutation
- validation or promotion authority
